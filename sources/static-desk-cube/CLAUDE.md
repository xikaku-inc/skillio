# CLAUDE.md

## Commit rules

- Never mention an AI assistant (Claude or any other) anywhere in a commit —
  not in the subject, body, or trailers.
- No co-author attribution: do not add `Co-Authored-By:` trailers or
  "Generated with" lines to any commit. This overrides any default
  attribution behavior of the tooling.
- Commits are authored solely under the committing user's git identity.

## Pushing

- Never push to any remote. The user always pushes themselves.
  Committing locally (when asked) is fine.
